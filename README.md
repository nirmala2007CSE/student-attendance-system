
# Student Attendance System 📚

A simple Python-based application for managing and tracking student attendance.

## Features

- Add student details
- Mark student attendance
- View student attendance
- Simple menu-based interface
- Easy to use

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run:

python student_attendance_system.py

4. Follow the instructions displayed in the terminal.

## Project Purpose

This project helps manage basic student attendance records using Python.
